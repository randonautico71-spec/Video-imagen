# Almanaque — lo esencial para hacer videos (sin proyectos)
Carpeta de consulta rapida. Los PROYECTOS (guion, escenas, datos) no se suben al repo; aqui solo vive el material reutilizable.

| archivo | para que sirve |
|---|---|
| `FIGURAS.md` | catalogo de todas las figuras de luz (nombre y que dibujan) |
| `COMPONENTES.md` | API de `VE.comp` y trucos aprendidos de composicion (posiciones, tiempos, brillo) |
| `patrones_escenas.js` | codigo reutilizable: fondos oscuros por capitulo, lago con luna, animacion de fusion, helpers |
| `VOCES.md` | perfiles de voz y medidas reales (silencio de cola de Melo, ritmo, pausas, comparacion con Carmen) |
| `REGLAS.md` | reglas fijas del usuario |
