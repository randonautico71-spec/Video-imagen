# Kit de animaciones 3D por código (EN CONSTRUCCIÓN)

Carpeta autónoma para copiar a cualquier proyecto: 13 estilos animados (`estilos/`, Canvas 2D en Chromium) y animales 3D por SDF (`sdf/`, Node en CPU). Catálogo en `catalogo.jpg`.

Estado: los estilos ya aceptan tiempo (`renderStyle(nombre, t)` en `estilos/pagina.html`) y se han probado sin errores a t = 1,5 s.
Pendiente: scripts de vídeo en `bin/`, la skill que pregunta el tipo de animación antes de decidir y el bloque para el CLAUDE.md del proyecto.
