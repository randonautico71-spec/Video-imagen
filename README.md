# Motor de video generativo (local, solo codigo)
Python/numpy/scipy + Node/Playwright/Chromium + ffmpeg. Voces locales (Piper, MeloTTS). Musica sintetizada. Sin servicios de pago.

Flujo: Project de claude.ai (guion + descripcion visual -> brief) -> Claude Code en este repo (`CLAUDE.md`) -> MP4 pesado + ligero.
Formatos: short (vertical <=3 min), youtube (16:9, 3 min-1 h), instagram (vertical ~5 min).
Empezar: `bash pipeline/instalar.sh` y despues los comandos de `CLAUDE.md`. Guia del Project: `PROJECT_INSTRUCCIONES.md`.
